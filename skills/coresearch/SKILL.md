# Coresearch

The selected lead owns framing, strategy, consequential decisions, synthesis,
and final verification. Coresearch supports Astra or GPT-6.1 Sol as lead; the
user or host selects the running model.

Delegate bounded gathering, implementation, testing, analysis, or review when
the expected benefit exceeds coordination cost; do trivial or tightly coupled
work directly.

For suitable delegated assignments, prefer GPT-6.1 Sol or a lower-cost capable
worker. Choose worker and reasoning effort by the task, available tools,
demonstrated reliability, and total cost to a valid result. Use an Astra worker
when its expected benefit warrants the additional cost. The lead remains
responsible for integrating and verifying its findings.

Workers own execution, validation, and correction within their assigned scope.
Prefer coarse assignments and completion/blocker events over recurring status
check-ins. Use the host's supported workers and routing; report limitations that
materially affect the assignment.

Finish the requested deliverable, including relevant validation and correction.
Resolve ordinary ambiguity from context; ask only when a consequential decision
cannot responsibly be inferred. Host permissions and the user's scope still apply.

Use existing project artifacts. For work spanning sessions, an optional
[brief](templates/brief.md) records the question, evidence, decisions, and next
useful action. A small task needs neither initialization nor a state ledger.

## On demand

Read only a reference that adds something needed for the current task; these are
resources, not stages or a required sequence.

| Need | Resource |
|---|---|
| Literature, citations, source collection | [Literature](references/literature.md) |
| Contribution design, evaluation plans, experiments | [Experiments](references/experiments.md) |
| Architecture, SOLID/DDD, research-code maturity, system contracts | [Engineering](references/engineering.md) |
| Gaps, contradictions, causal analysis, evidence audits | [Analysis](references/analysis.md) |
| Writing, argument structure, revision, review, rebuttal, release | [Manuscripts](references/manuscripts.md) |
| A bounded worker assignment | [Delegation](references/delegation.md) |

Keep empirical claims traceable to inspected sources or actual runs. A retrieved
file is not a verified claim. Preserve contrary evidence and unresolved limits
in the deliverable, not just in a worker transcript.
